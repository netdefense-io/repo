Quick Installation

Install the NetDefense agent on your OPNsense device with a single command:

curl -sSL https://repo.netdefense.io/install.sh | sh
🔒
Secure Installation: The installer automatically downloads the repository fingerprint and configures signature verification for all packages.
⚠
Important: This installation requires root privileges. Only run installation scripts from trusted sources. Designed for OPNsense firewall devices running on FreeBSD 14.

Manual Installation

If you prefer to configure the repository manually, follow these steps:

1. Install Repository Fingerprint

Download and install the repository signing key for package verification:

mkdir -p /usr/local/etc/pkg/fingerprints/netdefense/trusted
fetch -o /usr/local/etc/pkg/fingerprints/netdefense/trusted/netdefense \
  https://repo.netdefense.io/opnsense/fingerprints/netdefense/trusted/netdefense

2. Create Repository Configuration

Create the NetDefense repository configuration file with signature verification:

mkdir -p /usr/local/etc/pkg/repos
cat << EOF > /usr/local/etc/pkg/repos/netdefense.conf
NetDefense: {
    url: "https://repo.netdefense.io/opnsense",
    priority: 5,
    enabled: yes,
    signature_type: "fingerprints",
    fingerprints: "/usr/local/etc/pkg/fingerprints/netdefense"
}
EOF

3. Update Package Database

Refresh the package repository database:

pkg update

4. Install NetDefense Agent

Install the NetDefense package:

pkg install os-netdefense

5. Verify Installation

Confirm the package is installed correctly:

pkg info os-netdefense

What is NetDefense?

NetDefense is a comprehensive firewall management system that enables administrators to centrally manage and monitor network security devices at scale. The agent package allows your OPNsense firewall to communicate with the NetDefense management platform for:

  • Centralized configuration management
  • Remote task execution
  • Real-time monitoring and telemetry
  • Template-based configuration deployment
  • Audit logging and compliance tracking

Important Notes

🔒
Package Signing: All packages in this repository are cryptographically signed using SHA-256 fingerprints. The installation process automatically verifies package signatures to ensure authenticity and integrity.
⚠
Security Notice: Adding third-party package repositories to your firewall requires careful consideration. Only add repositories from trusted sources. Always verify the repository fingerprint matches the official NetDefense fingerprint.
ℹ
System Requirements:
  • OPNsense 25.7 or compatible version
  • FreeBSD 14 (amd64 architecture)
  • Network connectivity to repo.netdefense.io
  • Root/administrative access for installation

Uninstallation

To remove the NetDefense agent:

pkg delete os-netdefense

Repository Maintenance

To disable the repository without uninstalling the package:

rm /usr/local/etc/pkg/repos/netdefense.conf
pkg update

Verifying Repository Fingerprint

For security, you can verify the repository signing fingerprint:

cat /usr/local/etc/pkg/fingerprints/netdefense/trusted/netdefense

The fingerprint should show:

function: sha256
fingerprint: "97deed32012431768be5ccd10b34e145450e97890593c7b522eafe4fe9fdb99d"
